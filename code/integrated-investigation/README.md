# Reproduction

Use Python 3 with NumPy, SciPy and SymPy. `python code/integrated-investigation/test_integrated.py` runs nine manufactured algebra tests; `python code/integrated-investigation/experiments.py` reproduces the synthetic finite-mode moment table. The computation uses double precision, 500-point Gauss–Legendre quadrature and 48 Legendre basis functions; no physical material values are inferred. The coefficient Euclidean norm is **not** the physical control norm because the bases are not orthonormal after endpoint weighting. A tiny singular value or residual in this discretization is not a theorem about infinite-dimensional reachability. The implementation has no nonlinear solver, figure generation, or convergence certification. Existing tests use the repository's `/tmp/cycle4-env` environment when available.
