# Reproduction and limitations

Install `requirements.txt`; run `python code/sign-changing-nogap/test_moments.py`, `python code/sign-changing-nogap/study.py`, and `python code/sign-changing-nogap/verify_precision.py`. For the separate N=160 check run `python code/sign-changing-nogap/study.py --modes 160 --points 1200`. The main study uses three endpoint-compatible bases: polynomial, terminal-flat smooth, and analytic oscillatory. It whitens the actual quadrature Gram matrix and prints the resulting \(L^2\) norm, rank, singular values, fit residual, ten withheld temperature modes, and discrepancy after doubling quadrature. A fixed numerical rank cutoff of 1e-12 is used after Gram whitening. Positive constants are synthetic and satisfy the physical coefficient relation. The independent 60-decimal check uses exact sine transforms, not the same quadrature formula. Near singularity, whitening discards numerically unresolved Gram directions; this is disclosed in the code. Finite truncations do not solve the infinite moment problem, and the printed norm does not establish a continuous optimum.
