# Flat-correction reproducibility

Install the previous `code/sign-changing-nogap/requirements.txt`, then run `OPENBLAS_NUM_THREADS=1 python code/smooth-nonanalytic/study.py` and `python code/smooth-nonanalytic/test_operator.py`. Three flat-at-zero correction bases are used: polynomial, oscillatory, and compact bump families. A Nyström solution of \(I+T\) is fitted to finitely many *exactly derived* paired residuals plus the v(T)=0 and first-memory constraints. The full physical \(L^2\) Gram matrix \(\int e^{2\mu t}t^2v_i v_j dt\) is used for whitening. Printed errors distinguish enforced and ten withheld moments and show discrepancies between Q and 2Q; the Gram is evaluated at the lower Q. Basis- and tolerance-dependent numerical ranks do not establish an infinite kernel, a convergent candidate, or nonexistence. The 60-digit test independently checks the tail identity by quadrature, not a high-precision large-N solve. Parameters are synthetic, satisfying the physical coefficient relation.

The CSV `gram_condition` omits discarded directions, `sv_condition` includes the smallest returned design singular value, and `fprime0` comes from the jet of the Nyström analytic correction. `partial_memory_norm` includes only n+10 modes. Q/2Q discrepancies compare separate Nyström matrices, not rigorous error bounds.
