# Computation and limitations

Run the commands in `code/integrated-investigation/README.md`. Nine manufactured tests independently check a discrete nonconstant-temperature mass inverse, symbolic characteristic polynomial and asymptotic residual, matrix duality, matrix-exponential versus branch formula, and endpoint-basis distinctions. They test the algebra and numerics, not the PDE proof or thermodynamics. The code uses synthetic positive constants and no experimental data.

The moment experiment fits a unit first-memory target while nulling finitely many temperature modes using 48 weighted Legendre directions and 500-point Gaussian quadrature. For N=3,6,10,15,20 and endpoint, flat and gap profiles, reported double-precision singular values fall to or below numerical resolution. Example: for N=10 the gap row has reported smallest singular value about \(1.7\times10^{-23}\), numerical rank 5 at relative cutoff \(10^{-13}\), and residual about \(1.7\times10^{-7}\); endpoint-compatible nonflat controls report a small finite-truncation residual. These are basis- and cutoff-dependent diagnostics, not evidence for or against infinite-dimensional feasibility. The printed Euclidean coefficient norm is not the \(L^2\) control norm; no minimum-energy inference is valid. Spectral slow-root evaluation uses rationalization to reduce cancellation, but no high-precision independent experiment, quadrature convergence study, nonlinear solver, physical validation or figure-generation pipeline was completed. The numerical programme is incomplete relative to the request.
