# Cycle 10: what is and is not reachable

All positive results here are for the **linearized odd** system with controls supported in a fixed interval ending before the preparation endpoint.

1. **Without terminal temperature constraint:** \(\mathcal K_o:U\to H_o\) is bounded and has dense range, and \(\Pi_{V_N}\mathcal K_o\) is onto \(V_N\) for every finite \(N\). The proof is exact via the full signed adjoint synthesis, not numerical rank. Smooth compact controls can realize the finite projections. No bounded inverse, uniform control cost or \(H^2\)-dense range is claimed.
2. **Exact finite sine target, without terminal temperature constraint:** for the fixed-gap control class, even this is impossible unless the target is zero. Indeed if \(p_n(0)=0\) for every \(n>N\), equation (2) of the terminal-constraint report implies \(F(\lambda_{n,+})=F(\lambda_{n,-})\). The right side is exponentially small in \(q_n^2\), while \(\lambda_{n,+}+\mu\asymp q_n^{-2}\). The entire-function Taylor argument there forces \(F\equiv0\), so the control and all memory coefficients vanish. Thus density and finite projected surjectivity coexist with \(\operatorname{ran}\mathcal K_o\cap V_N=\{0\}\); projection must not be mistaken for exact membership. In particular \(\mathcal K_o\) has trivial kernel on this class.
3. **With exact \(Y(0)=0\):** the terminal-constraint theorem gives \(\ker\mathcal A=\{0\}\), so constrained odd memory range is \(\{0\}\), its projection is zero, and it cannot approximate a fixed nonzero odd target in \(L^2\) or \(H^2\). This is exact for the chosen linearized fixed-gap class only.
4. **Nonlinear and no-gap controls:** whether a fully coupled positive preparation can reach nonzero odd memory while \(y(0)=0\) remains OPEN. Neither linearized density without the constraint nor the linearized obstruction proves nonlinear reachability or its impossibility. Nonlinear constraints, even components, and \(H^2\) terminal regularity still need separate proof.

A desired nonzero \(h\in V_N\) can be approximated in \(L^2\) by unconstrained linearized terminal memories, but these generally have nonzero temperature and nonzero high-mode tails. No \(H^2\) approximation is inferred. The physical end condition is exact across the whole bar, not merely its two endpoint values.
