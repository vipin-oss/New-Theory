# Cycle 6: search for an actual invisible trajectory

**Decision: no actual nonzero invisible state found.** The full signed reference comparison is injective, so it cannot furnish a counterexample. The failure of a polynomial observability inequality—even for that injective reference—is a stability obstruction, not invisibility.

The actual search must solve, for \(h\in H_o\setminus\{0\}\),
\[Y(0)=0,\ P(0)=h,\ MY_t-\kappa Y_{xx}=BY+SP,\ P_t+\mu P=\gamma Y,\quad Y|_{\partial I}=0,\quad Y_x(0,t)=0\text{ for a.e. }t\in J.\tag{1}\]
Coefficients are generated by the prescribed **nonzero** loading and the actual base, with \(b,g_*,k,\lambda\ne0\). The forward evolution on \((0,\delta)\) is part of (1); \(Y(\delta)=Gp\), \(p=P(\delta)=D_\delta h\), not free independently. Odd reflection implies \(Y_x(L,t)=Y_x(0,t)\), not interior \(Y=0\). Under the extra nonvanishing-\(S\) threshold, \(F=SP\) remains an unknown distributed source. Substituting \(Y=0\) into (1) then forces \(SP=0\), \(P=0\) on \(J\), and, by invertibility of \(D_\delta\), \(h=0\); hence the simplistic zero-temperature ansatz cannot be nontrivial. Outside that nonvanishing threshold this observation is not asserted.

To search nontrivially one would need an exact \(Y\ne0\) with zero Cauchy flux whose induced \(P\) both satisfies the ODE and is generated by an admissible \(h\) throughout the pre-delay interval. Replacing \(SP\) by an arbitrary source can create invisible manufactured functions but does not satisfy that constraint. Reference eigenmode truncations, small singular values, rank-one abstract perturbations, and high-frequency near-cancellation fail at least one of the seven physical requirements and are not counterexamples.

The input classes must remain separate: a hypothetical \(h\in H_o\) need not lie in \(X_o=H^2\cap H_o\); an \(X_o\) state need not have a fully coupled thermomechanically admissible past. Testing the latter additionally requires the complete strain-equilibrium, heat and constitutive ODE for the past, the prescribed load and endpoints. No material parameters or active-base fields were supplied, so no actual-system numerical run is claimed. A future numerical diagnostic must use supplied constants and a posteriori discretization/error separation; even a computed zero singular value would not prove (1) exactly.
