# Cycle 7: several loading histories, one initial memory

Take a finite list of prescribed displacement histories \(g_j\), each physically admissible and with the **same** parameters, geometry, bath, initial temperature and initial state \(h\). This is an explicitly different experimental protocol, not a silent replacement of the frozen \(g_*\sin^2(\pi t/T)\). Assume each active base and its full forward/transposition theory have been established; the existing quantitative theorem verifies this only for the original small nonzero loading under its hypotheses. Let \(\mathcal T_j:H_o\to L^2(J_j)\) be its actual odd flux-difference derivative and define \(\mathbb T_m h=(\mathcal T_1h,\dots,\mathcal T_mh)\). Then
\[\ker\mathbb T_m=\bigcap_{j=1}^m\ker\mathcal T_j,\qquad \mathbb T_m^*(f_j)=\sum_j\mathcal T_j^*f_j,\qquad \mathbb T_m\text{ injective}\iff\overline{\sum_j\operatorname{ran}\mathcal T_j^*}=H_o.\]
The equality of kernels is exact, but strict improvement is equivalent to an unproved strict intersection. For each experiment, where the \(D_{j,\delta_j}\) threshold applies, \(\mathcal T_j=O_jD_{j,\delta_j}\); the graph and propagated memory are experiment-specific. A common factorization by a reference operator is not available.

On a fixed prior \(V_N\), the joint Gram matrix is \(\Gamma_{i\ell}=\sum_j\langle\mathcal T_j\phi_i,\mathcal T_j\phi_\ell\rangle\) (with indices \(i,\ell\)); its minimum eigenvalue is positive iff the restriction is injective. Adding a component cannot decrease this eigenvalue, but **strict** improvement is not automatic. If the original experiment already satisfies its explicit small-load threshold, the joint lower bound is at least \(\sigma_N/2\); no additional experiment is needed for that conditional theorem. A computed Gram for other loads requires a certified forward/discretization error and is not a physical proof by itself.

## Equation-derived sensitivity of the loading design

In a differentiable family \(m_\varepsilon=m_0+\varepsilon f\), denote derivatives of the actual base by dots. Direct differentiation of the frozen coefficients gives
\[\dot M=d\dot y_b,\quad \dot B=-dQ\dot y_{b,t}-b\dot E_b-br\gamma\dot y_b+2k\gamma\dot w_b,\quad \dot S=\mu(br\dot y_b-2k\dot w_b).\]
At any base where the parameter derivative is justified, the derivative of the **whole input-output operator** follows from the zero-initial-data tangent system
\[M\dot Y_t-\kappa\dot Y_{xx}=B\dot Y+S\dot P-\dot M Y_t+\dot B Y+\dot S P,\quad \dot P_t+\mu\dot P=\gamma\dot Y.\]
Its boundary trace is \(2A_0\kappa\dot Y_x(0)\). Thus load changes enter the actual coefficient evolution and the complete past, not as a proved scalar multiplier. At the equilibrium comparison \(m_0=0\), \(\dot y_b\) solves the linear heat response forced by \(-b\theta_* f'\), coupled to its own memory; if \(f'\not\equiv0\), \(\dot y_b\not\equiv0\) (otherwise its memory is zero and the equation forces \(f'=0\)). Therefore \(M\) genuinely changes to first order. This is not a proof that \(\dot{\mathcal T}\ne0\), nor of new kernel separation. Differentiability and trace bounds are conditional on the strong forward theory for the chosen family.

* **Amplitude and sign:** two opposite small amplitudes can give different bases as above. Neither sign change nor a different coefficient proves independent measured histories. Calibration should include exact waveform, not amplitude only.
* **Profile and duration:** altering \(f\) or the terminal time changes the base, \(A_\delta,D_\delta\) and \(J\); use a fresh well-posedness/trace estimate for each, and hold the constitutive law fixed. Shorter or longer duration has no established monotonic kernel advantage across distinct experiments.
* **Delay:** with the **same** full run and common end time, if \(J_2\subset J_1\), the second record is a restriction of the first; the stacked map has exactly the same kernel and equivalent data norm. Earlier observation can add information only if actually acquired; no strict kernel reduction follows.
* **Repeatability:** the experiment consumes/evolves the initial memory; independent runs require a preparation that reproduces the same full \(h\), not merely the same measured force. Cross-run drift is model error. If this cannot be guaranteed, the common-unknown joint model is inapplicable.

On a common observation interval, an equation-derived perturbation bound \(\|\mathcal T_j-\mathcal T_0\|_{V_N\to L^2}\le\epsilon_j<\sigma_N\) transfers the **finite** reference lower bound, as previously proved for the original loading. There is no corresponding infinite-dimensional norm-perturbation argument: the reference inverse is not bounded below and small perturbations need not preserve injectivity.
