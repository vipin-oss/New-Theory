# Cycle 8: what would materially strengthen the paper?

The highest-priority **single next task** is a rigorous, physically interpretable coupled-past preparation result for a nontrivial subset of the finite prior, or a precise obstruction showing the assumed finite prior cannot arise under the proposed preparation. It targets the gap between a formal initial internal variable and an experimentally meaningful unknown. Specify the permitted past boundary actuation and thermal bath before proving anything: the frozen post-zero loading and equations must remain unchanged. Do not assume a prehistory protocol or claim \(V_N\) reachable.

| Candidate | Assumptions and route | Existing information / required work | Feasible without actual parameters? / contribution |
|---|---|---|---|
| 1. Explicit computable \(\sigma_N\) lower bound | Fixed signs, finite \(N\), \(0<\delta<T\); compute exact exponential Gram entries, use certified interval arithmetic/eigenvalue enclosure or an analytic determinant-plus-upper-eigenvalue bound. Distinct rates show strict positivity but can be ill-conditioned. | Formula and positivity exist; certified arithmetic and a stable algorithm with rounding control are missing. | Yes symbolically or with a clearly artificial nondimensional set; useful for reproducibility, but not physical validation. An exact expression via finite Gram eigenvalue is already computable in principle, not a certified numerical lower bound. |
| 2. Verified load threshold | Explicit dimensionless parameters, \(N,\delta\), exact output scaling and certified \(\sigma_N\), all existing constants recomputed. | Constants are provided but extremely conservative; material values and certified numerical evaluation missing. | Yes for a labeled manufactured dimensionless set, not evidence for an actual specimen. Important feasibility check, not by itself experimental significance. |
| 3. Finite acquisition theorem | Existing \(L^2\) trace and reference analytic kernels; time bins and Poincaré. | **Achieved in this cycle**: explicit sufficient bin width and nonlinear lower bound in `cycle8-discrete-acquisition-error-analysis.md`. Point samples still need extra trace/quadrature regularity. | Yes symbolically. A useful model-specific corollary but closely overlaps established projection results. |
| 4. Certified PDE solver | Stable discretization for nonlocal mass, memory ODE and nonlinear base, proven energy/trace consistency; error control for \(N\) columns and flux observations, including time/space discretization. | Existing parameterized base, Galerkin and finite-difference diagnostic solvers are not certified enclosures. Need a convergence/error proof, implementation as needed, and inverse error propagation. | Possibly for abstract dimensionless inputs; a substantial separate project. Relevant for reproduction but cannot validate physics alone. |
| 5. Preparation | Prescribed physically allowed history controls and bath; solve full mechanical equilibrium, temperature and memory evolution throughout the preparation interval, land at the required fixed initial temperature, displacement and desired odd internal state. Then characterize a nontrivial reachable subset and its topology, or prove a specific obstruction. | `direction-2-physical-history-admissibility-theorem.md` proves only constitutive and slice compatibility, not full coupled evolution. Past waveform/control class and attainable states remain unspecified. | Potentially symbolic, but success is not guaranteed. **Most material:** it determines whether the finite-prior claim describes realizable unknowns rather than only an imposed mathematical state. |
| 6. Thermal-coupling comparison | Use an explicitly labeled auxiliary \(b\to0\) family, not the frozen actual experiment; retain \(a,k,\lambda,\kappa\). For zero-base reference, \(S_0\propto b\), so at \(b=0\) initial-memory-to-heat response is zero. | The elementary limiting reference observation follows from the equations; a quantitative conditioned comparison for nonzero \(b\) and the actual base still needs proof. | Yes symbolically. The zero-coupling result is unsurprising and does not alone make a paper or imply monotonic sensitivity for nonzero coupling. |

The new bin theorem partially closes acquisition rigor, but it does not resolve point sampling or physical state preparation. Without the preparation result, an honest mathematical note may still be conceivable, yet a physically motivated paper claiming meaningful recoverable memory would not be justified. A negative preparation theorem would itself be useful and could change the decision.
